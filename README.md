# Po kolejích z Prahy

Jednoduchý studentský průvodce výlety vlakem z Prahy. Sedm statických HTML stránek, společné CSS a JavaScript bez frameworku.

## GitHub Pages

Připraveno pro repozitář `9yttm8r4h7-droid/Vlakem-z-Prahy` a adresu https://9yttm8r4h7-droid.github.io/Vlakem-z-Prahy/ . Před zveřejněním musí být v nastavení repozitáře zapnuté Pages: Deploy from a branch, main, / (root).

Obsah této složky patří přímo do kořene repozitáře. Hlavní soubor je index.html; vedle něj musí být složka assets. Soubory není potřeba sestavovat. Soubor .nojekyll vypíná zpracování Jekyllem.

Texty měň v příslušném HTML, vzhled v assets/style.css a funkce v assets/script.js. Pro změnu adresy oprav canonical odkazy v head všech deseti stránek. Canonical doporučuje hlavní adresu vyhledávačům; není to přesměrování serveru. GitHub Pages nepoužívá soubor _redirects, proto zde není přiložen.

## Fotografie a obsah

Autorem studentského projektu je Filip Průša. Fotografie jsou zatím převzaté; autoři, původní odkazy a licence jsou uvedené na stránce o-webu.html. Vlastní snímky budou doplněny později. Informace o cestách jsou tipy k plánování, nikoli živý jízdní řád.

Úvod má záměrně jen tři doporučené karty, přehled vylety.html obsahuje všech šest. Další výlet se přidává do přehledu a jako vlastní HTML stránka. CSS ani JavaScript není třeba měnit.
